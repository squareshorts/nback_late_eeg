# Exploratory models (not used in the manuscript)

These files preserve numerical provenance for mechanistic hypotheses that were tested and rejected as primary interpretations.

- `stuart_landau/`: corrected Hopf/Stuart-Landau simulations. The empirical effect did not require crossing the Hopf point.
- `isochron/`: isochron-geometry consistency calculations. Direct empirical phase controls did not support using phase-dispersion as the manuscript mechanism.

Do not cite these exploratory files as confirmatory evidence for the manuscript. See `../MODEL_SELECTION.md`.
